# Mahesh – BQ1 (Milestone 2)

This folder contains my individual contribution for Milestone 2 of the BA820
project. The analysis addresses Business Question 1 (BQ1), which examines whether
medicines withdrawn or denied approval exhibit meaningful similarity patterns
relative to approved medicines using European Medicines Agency (EMA) data.

## Files
- `M2_mahesh_BQ1_similarity.ipynb`: notebook containing unsupervised
  text-based similarity analysis, exploratory clustering attempts, and
  supplemental visualizations.

## Notes
Regulatory outcomes are used only for interpretation and are not incorporated
into the construction of similarity measures or exploratory analyses.
