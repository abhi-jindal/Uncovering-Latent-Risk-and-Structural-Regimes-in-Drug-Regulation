# Uncovering-Latent-Structures-in-Drug-Regulation
This project applies unsupervised learning and unstructured text analysis to uncover latent regulatory risk structures and monitoring regimes in European drug regulation. Using clustering, semantic similarity analysis, stability regime discovery, and sponsor archetype modeling, the project identifies structural regulatory risk profiles and evaluates the consistency of Additional Monitoring assignment.

By integrating medicine-level regulatory features, therapeutic indication text, and sponsor-level organizational characteristics, the analysis reveals multi-level structural patterns that shape regulatory stability and monitoring prioritization. The results provide a structural framework for understanding regulatory uncertainty and identifying medicines with regulatory risk profiles similar to monitored medicines.

This project demonstrates how unsupervised learning can support regulatory insight, pharmacovigilance prioritization, and policy evaluation by uncovering structural patterns not visible through traditional outcome-based analysis.
